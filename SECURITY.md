# Security Policy

## Supported Versions

`ZanobiJS` is in active beta (`1.2.0-beta.x`). Only the latest published version of `@zanobijs/core` and `@zanobijs/common` is supported with security fixes — there are no maintained stable/LTS lines yet.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

Use [GitHub's private vulnerability reporting](https://github.com/devdroide/ZanobiJS/security/advisories/new) for this repository. This creates a private advisory visible only to the maintainers until a fix is ready.

If that's not available to you, contact the maintainer directly via GitHub: [@devdroide](https://www.github.com/devdroide).

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (a minimal repro is very helpful)
- The affected version(s)

## What to Expect

- Acknowledgement of your report as soon as possible
- An assessment of the issue and, if confirmed, a plan for a fix
- Credit in the release notes, if you'd like it

## Scope

This policy covers the packages published from this repository (`@zanobijs/core`, `@zanobijs/common`, `@zanobijs/cli`). Vulnerabilities in third-party dependencies should be reported upstream as well — if it also affects how `ZanobiJS` uses that dependency, please still let us know.
